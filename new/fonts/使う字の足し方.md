# 筆ごしらえ（大学名の筆文字）の使う字の足し方

トップの「注目の試合」の背景の大学名は、書体「筆ごしらえ」（SIL Open Font License 1.1、配布：isMe）で出しています。
元のファイルは 8MB あるので、大学名に使う字だけを取り出した `fude-goshirae-sub.woff2`（約 56KB）を置いています。

入っていない字は Yuji Boku（Google Fonts）で出ます。新しい大学が入って字が足りないときは、次の手順で作り直してください。

1. 元のファイル `fude-goshirae.ttf`（配布元の zip に入っています）を用意する
2. 使う字を `chars.txt` に書く（今の字は、このファイルの下の「今入っている字」）。新しい字を足す
3. 次を実行する（Python の fonttools と brotli が必要：`pip install fonttools brotli`）

   pyftsubset fude-goshirae.ttf --text-file=chars.txt --flavor=woff2 --output-file=fude-goshirae-sub.woff2

4. できた `fude-goshirae-sub.woff2` を、このフォルダのものと入れかえる（`OFL-fude-goshirae.txt` と `README-fude-goshirae.txt` は消さない）
