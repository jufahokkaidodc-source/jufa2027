# BATTLE BRUSH — 注目の試合（トップ）の構成

対象ファイル：`new/index.html`（jufa・jufa2027 とも同じ）。書体：`new/fonts/`。

## 1. 重なりの順（下から）

| 層 | 要素 | 中身 |
| --- | --- | --- |
| 1 | `.mv-bg`（背景） | 2チームの色を縦にまっすぐ半分ずつ（`--hc`＝ホーム、`--ac`＝アウェイ）＋全体を少し暗くするグラデーション |
| 2 | `.mv-bg .sb`（筆あとの柄・SVG） | 左半分を作り、右は鏡うつし（`<use href="#hl">`）。左は左上→中央下、右は右上→中央下へ流れる白・黒の筆あと、かすれ、しぶき。まん中はマスクでうすく（日付を読みやすく） |
| 3 | `.mv-nm`（筆文字の大学名） | 書体「筆ごしらえ」。PC：上に大きく横書き（ホーム左・アウェイ右）。スマホ：半分の外側に縦書き（大きさは JS の mvNmFit が決める）。エンブレムの後ろ |
| 4 | `.mv-in`（情報） | エンブレム・大学名・リーグ名と節・日付・キックオフ・会場・「試合情報はこちら」・点（カルーセル） |

層1〜3は背景で、文字情報とボタンはすべて層4（Webサイトの表示データ）です。画像には文字を焼きこみません。

## 2. HTML

```html
<section class="mv hero" id="mv">
  <div class="mv-bg" id="mvBg">
    <svg class="sb" viewBox="0 0 1600 800" preserveAspectRatio="xMidYMid slice">…筆あと…</svg>
    <div class="mv-nm" id="mvNm"><!-- JS が <div class="l"><span>北翔</span></div><div class="r"><span>大谷</span></div> を入れる --></div>
    <svg width="0" height="0"><filter id="mvInk">…文字のかすれ…</filter></svg>
  </div>
  <div class="mv-in"> …エンブレム・日付・ボタン… </div>
</section>
```

## 3. 色と文字の自動切りかえ（カラーマスター）

- 背景の色：チーム紹介の「チームカラー」（近い色どうしは、サブカラーか暗くした色に）→ `--hc` / `--ac`
- 筆文字：略称の最後の「大」を取る（北翔大→北翔。1文字になるときは取らない）
- 筆文字の色：赤系のチームは生成り（#f3e9dc）、ほかはチームカラーを明るくした色（金・水色など）→ `--nkh` / `--nka`
- 試合が切りかわるたびに、上の3つを入れかえる（`showMV`）

## 4. 大きさ（縦幅は変えない）

- PC：注目の試合の高さはこれまでどおり（例：1280px 幅で 563px）。筆文字は「半分の幅の 86% ÷ 字数」か「高さの 44%」の小さいほう
- スマホ：高さはこれまでどおり（例：390px 幅で 448px）。筆文字は半分の外側に縦書き。上からエンブレムの上のほう（エンブレムの高さの 35%）までに入る大きさ
- 横向きの低い画面：エンブレムと日付を高さに合わせて小さく
